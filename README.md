# Instagram DM Extractor

A lightweight Chrome extension to export Instagram direct messages into multiple formats including JSON, Markdown, and HTML.

## ✨ Features

- 📥 Export Instagram chats instantly
- 📅 Filter messages by date range
- 📊 Built-in conversation statistics
- 📝 Download chats as:
  - JSON
  - Markdown (.md)
  - HTML
- ⚡ Simple and fast extraction process
- 🎯 Clean popup interface
- 🔒 Runs locally in your browser

---

## 📂 Supported Export Formats

### JSON
Structured raw message data for developers and analysis.

### Markdown
Readable chat format for notes, archives, and GitHub storage.

### HTML
Beautiful formatted chat export viewable in any browser.

---

## 🚀 How to Use

1. Install the Chrome extension
2. Open Instagram in your browser
3. Navigate to any DM conversation
4. Open the extension popup
5. Choose a date range
6. Click **Extract Messages**
7. Download the exported file format you want

---

## 📊 Included Statistics

The extension can generate useful chat insights such as:

- Total message count
- Average messages per day
- Message count per sender
- Conversation initiations
- Average response time
- Message type breakdown

## 🔒 Privacy

This extension processes data locally inside your browser.

No messages are uploaded to external servers.

---

## 📌 Notes

- Make sure you are logged into Instagram before using the extension.
- The extension only works on Instagram DM pages.
- Large conversations may take additional extraction time.
